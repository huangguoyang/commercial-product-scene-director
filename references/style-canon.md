# 风格母版

## 目标

从多张参考图提炼一段「跨图共性、可复用」的视觉 DNA，压缩成风格前缀块，供系列里每一条提示词开头原样复用。它不是任何一张参考图的复述，而是多图之间的「交集」。

## 默认取向：真实拍摄

除非参考图或用户明确指向渲染/插画，媒介默认**真实摄影**。提炼时优先识别参考图是「影棚实拍」还是「样板间/展厅实景」，并按 [真实实拍与高级配色](photographic-realism.md) 提炼摄影语言、氛围感来源与配色关系，而不是只写「高级、氛围感」等空词。

## 交集而非并集

- 出现在**多数**参考图里的特征 → 进入母版。
- 只在**单张**图出现、且用户没有点名 → 不进母版。
- 只在单张图出现、但极强且用户点名参考 → 作为「点睛」进入母版，并标注「仅来自参考图 N」。
- 参考图之间互相矛盾（如有的暖、有的冷）时，不强行平均；优先采信用户点名的图，或写明「主体倾向 X，局部保留 Y」。

## 提炼维度

按这八个维度逐项观察，每个有证据的维度才写，不凑齐：

1. **媒介与编辑语言**：真实摄影 / 影棚 / 样板间实景 / 3D 渲染 / 插画；真实感还是渲染感；商业广告还是 editorial 时尚。
2. **色彩系统**：主色、辅色、点缀色；冷暖、饱和、明度、黑白灰占比；按 [高级配色方法论](photographic-realism.md) 提炼「骨架色 + 记忆点色」，取 4–6 个近似 HEX（作用 + 占比）。
3. **光线系统**：光源方向、软硬、色温、曝光、明暗关系、阴影与高光、轮廓光、时间感。
4. **摄影语言**：机位与焦段感、景深、hero shot、软装密度、生活痕迹、陈设语言、杂志/广告摄影特征。
5. **材质与表面质感**：微对比、颗粒、柔焦、锐化、光泽、空气透视、接触阴影、环境反光。
6. **构图语言**：景别、机位、主体占比、负空间、前中后景、视觉动线。
7. **氛围与叙事调性**：情绪、时代感、品牌气质；「氛围感」要落到光、层次、生活痕迹、留白上，不写空词。
8. **成像签名**：见下节四层分离。

## 成像签名四层分离

把成像机制分成四层判断，不互相覆盖：

1. **固有属性**：物体原本的颜色与材质。
2. **光线层**：光源方向、色温、软硬、阴影、轮廓光。
3. **曝光层**：全局/局部曝光、动态范围、高光是否接近溢出、暗部是否压低。
4. **后期/渲染层**：微对比、锐化、柔焦、颗粒、色偏、光晕、压缩、印刷/扫描。

跨层描述可以同时成立。同一层出现冲突时回到参考图证据重判。成像签名写「成像系统」而非主题内容。

## 风格前缀块

把母版压缩成一段**固定文字**，作为系列里每条提示词的开头原样复用：

```text
风格前缀块：[媒介与编辑语言（真实摄影定位）] + [成像签名/整体气质] + [色彩系统] + [光线系统] + [摄影语言] + [材质质感]
```

要求：

- 用连续中文自然语言，不出现模块标签、英文键或占位符。
- 只写有画面证据的事实；「高级、氛围感、精致」等空词换成可执行描述（光的方向、景深、配色骨架、生活痕迹）。
- 不承诺还原原作者提示词；交付的是基于画面证据重建的高还原生成指令。
