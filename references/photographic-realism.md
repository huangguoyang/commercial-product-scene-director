# 真实实拍、影棚/样板间与高级配色审美

## 目标

把「真实拍摄」确立为默认成像取向，并给出影棚/样板间实拍的摄影语言、氛围感来源与高级配色方法。目标是让提示词导向「像真实相机在影棚或样板间里拍出来的照片」，而不是 3D 渲染、插画或 CG 质感。

## 默认取向：真实拍摄

- 除非参考图或用户明确指向渲染/插画，否则媒介默认是**真实摄影**。
- 用「真实相机实拍」的措辞锚定成像系统，避免落入渲染感：写「真实摄影、f/xx 景深、自然透视、环境反光、接触阴影」，而不是「3D 渲染、CG、插画、数字艺术」。
- 允许并保留真实摄影的「不完美」：轻微景深虚化、自然阴影软边、反光/倒影、克制的颗粒与生活痕迹——这些正是实拍氛围感的来源。

## 两类实拍场景语言

### 影棚（studio）实拍

- 可控人工光：主光 + 辅光 + 轮廓光；柔光箱/雷达罩质感，高光过渡柔和，阴影方向一致。
- 简洁背景：无缝背景纸、渐变背景、轻微投影，产品是绝对主角。
- 情绪：商业 hero shot、精修杂志感、克制留白、干净但不塑料。

### 样板间 / 展厅（showroom）实景

- 真实室内环境：地面、墙面、窗帘、家具、绿植；软装密度适中，不凌乱。
- 自然光 + 人工光混合，时间感明确（晨光/午后/傍晚）。
- 生活痕迹与陈设语言：产品「被使用/被陈列」，有尺度参照物（一本书、一杯咖啡、一株绿植）。
- 情绪：高级、宜居、有氛围，克制、不廉价。

## 摄影语言维度（进入风格母版）

- 机位与焦段感：平视 / 俯视 / 低机位；35mm 广角空间感、50mm 自然、85mm 压缩感。
- 景深：浅景深虚化背景突出产品，或大景深交代完整空间。
- hero shot：产品作为画面绝对视觉中心的商业主视觉。
- 软装密度、生活痕迹、陈设语言：决定「样板间感」与「氛围感」的浓度。
- 杂志/广告摄影特征：编辑式构图、留白、质感统一、视觉动线。

## 高级配色方法论

高级感不来自「颜色本身高级」，而来自「颜色与材质、光线配合出的和谐」。写配色时永远同时写材质与光。

- **骨架**：黑白灰/中性色打底（占最大面积），1 个主色 + 1 个点缀色形成记忆点。
- **克制**：低饱和、材质本色优先，避免高饱和撞色；点缀色小面积、高纯度，只用于聚焦。
- **关系**：邻近色 + 少量对比色；冷暖呼应；明度对比负责层次，色相对比负责情绪。
- **落地**：参考色卡只取真正影响画面的 4–6 色，标注作用与大致占比；黑白灰图也要区分背景、主体、阴影、高光。

## 氛围感来源（进入场景与光线）

- 光：方向明确的柔光/侧光/逆光轮廓；色温统一；明暗有层次。
- 层次：前中后景 + 空气透视 + 景深，避免「贴图感」。
- 生活感：克制的陈设与生活痕迹，点到为止，不堆砌。
- 留白：负空间与呼吸感，避免塞满。

## 反渲染词库

正向用实拍词，负向排渲染词：

- **避免**：塑料感、CG 感、游戏引擎、3D 渲染、超光滑、无阴影、漂浮、贴图、过饱和、色块生硬。
- **正向**：真实摄影、自然透视、接触阴影、环境反光、材质纹理、轻微景深、时间感、生活痕迹。
