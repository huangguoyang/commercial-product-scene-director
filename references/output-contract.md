# 输出合同与提示词组织

## 目标

把「风格母版 + 产品身份锁 + 场景方案」组装成可直接复制的中文生成提示词，并保证系列一致、产品保真、真实实拍。

## 默认交付模板

```text
# 风格母版（跨参考图共性）
[媒介/编辑语言、成像签名、色彩系统、光线系统、摄影语言、材质质感、氛围调性]
风格前缀块：...

# 产品身份锁（不可改变）
[结构/轮廓、颜色分区、材质、品牌元素]
产品锁块：...

# 场景方案（系列一致，仅场景变化）
## 场景 1：{方向 + 叙事一句话}
审美要点：...
产品位置：...
完整提示词：...

## 场景 2 / 3 ...

# 使用建议
画幅默认 16:9；可选：把产品图作为参考图/垫图以更稳保形。
```

## 单条提示词组织顺序

```text
媒介与整体成像签名（风格前缀块，含「真实摄影」定位）
→ 画幅、机位、焦段感、构图与空间骨架
→ 产品身份锁（结构/颜色分区/材质）
→ 产品自然落地（尺度、接触面、透视、光影匹配）
→ 场景与叙事（环境、道具、前中后景、生活痕迹）
→ 光线与色彩（含高级配色骨架）
→ 材质与成像质感（实拍质感，反渲染）
→ 产品保真防线（负向）
```

## 要求

- 用一段连续、可直接复制的中文自然语言，不输出模块标签、项目符号、英文键或占位符。
- 风格前缀块与产品锁块在系列内逐条**原样复用**，只有场景叙事块变化。
- 一个事实只进入一次提示词，不重复堆同义词。
- 默认用「真实摄影」措辞，避免渲染感；写光的方向、景深、配色骨架、生活痕迹，不写空词。
- 不编造品牌、镜头型号、身份或不可见区域。
- 保真防线放末尾，只针对当前产品，不写通用负面词清单。

## 覆盖审计（输出前逐项核对）

1. 风格前缀块是否在每条开头原样复用，是否锚定「真实摄影」。
2. 产品锁块是否在每条中原样复用（含颜色分区）。
3. 画幅是否默认 16:9（或按用户指定）。
4. 产品结构/颜色分区/材质是否进入正向锁 + 负向防线。
5. 产品自然落地（尺度/接触/透视/光影）是否写进每条提示词。
6. 场景变化是否只发生在叙事/构图/环境层，未改变风格母版。
7. 是否新增了母版/锁块之外的无证据事实。
8. 保真防线是否紧凑且针对当前产品。

任一生成敏感项未覆盖时，先修订提示词再交付。
