# 场景衍生与系列一致性

## 目标

在「风格母版 + 产品身份锁」都固定的前提下，沿叙事与审美两个轴衍生多个场景方案；所有场景共享同一母版与锁块，只有场景/叙事/构图变化，从而保证系列一致、审美一致。

## 两个轴

- **叙事轴（讲什么）**：场景故事、使用情境、情绪节拍、产品在场景中的角色——主角 / 道具 / 功能演示 / 品牌态度。每个场景一句话点明叙事。
- **审美轴（怎么讲）**：构图、光线叙事、色彩情绪、质感层级、商业大片调性。审美轴必须从风格母版继承，不另起炉灶。

## 每个场景方案包含

```text
叙事一句话：...
审美要点：构图/机位/光线情绪/前中后景各一句
产品位置：产品在该场景中的位置、朝向、大小、可见角度
完整提示词：...
```

## 系列一致性机制

- 「风格前缀块」在每条提示词**开头原样复用**，锁住媒介、成像签名、色彩、光线、质感。
- 「产品锁块」在每条提示词**原样复用**，锁住结构、材质、颜色。
- 只有「场景与叙事块」在系列内变化：环境、道具、前中后景、情绪、机位。
- 每个场景沿用母版的同一套色彩系统与光线系统；不同场景之间只调「用量」和「落点」，不换系统。

## 场景差异化

在母版一致的前提下做变化，靠这些维度：

- 构图与机位（特写 / 中景 / 全景、俯 / 平 / 仰、负空间分配）。
- 环境与道具（材质、体量、多少），但道具材质与场景质感要服从母版。
- 情绪节拍（叙事从「开箱/静置」到「使用/沉浸」）。
- 前中后景层次与产品在画面中的占比。

不靠「换风格」来制造差异。

## 数量与画幅

- 默认画幅 16:9；用户可覆盖。
- 未指定场景数量时给 3 个差异化场景；用户要求 N 个就出 N 个。
