# 场景衍生与系列一致性

## 目标

在「风格母版 + 产品身份锁」都固定的前提下，沿叙事与审美两个轴 + 默认方向库衍生多个场景方案；所有场景共享同一母版与锁块，只有场景/叙事/构图变化，从而保证系列一致、审美一致。

## 两个轴

- **叙事轴（讲什么）**：场景故事、使用情境、情绪节拍、产品在场景中的角色——主角 / 道具 / 功能演示 / 品牌态度。每个场景一句话点明叙事。
- **审美轴（怎么讲）**：构图、光线叙事、色彩情绪、质感层级、摄影语言、氛围感。审美轴必须从风格母版继承，不另起炉灶。

## 默认方向库

未指定方向时，从下面六个方向里挑差异最大的几个（默认 3 个）；按产品类型把「空间功能」替换成符合真实使用逻辑的空间，不硬凑：

1. **日间主视觉（hero shot）**：通透自然光、完整空间、商业主视觉，产品是绝对焦点。
2. **安静生活角**：更亲密的尺度、柔和侧光、克制的陈设与生活痕迹。
3. **开放使用场景**：与相邻功能区形成空间关系，强调真实使用、自然落地。
4. **建筑感广角**：更强的线条、留白与空间层次，产品仍是明确视觉中心。
5. **材质细节近景**：突出产品与环境材质的协调，浅景深，但不裁掉关键身份结构。
6. **夜间氛围**：暖色人工光 + 层次化局部照明，产品颜色仍准确。

## 每个场景方案包含

```text
方向 + 叙事一句话：...
审美要点：构图/机位/光线情绪/前中后景/生活痕迹各一句
产品位置：产品在该场景中的位置、朝向、大小、可见角度、接触面
完整提示词：...
```

## 系列一致性机制

- 「风格前缀块」在每条提示词**开头原样复用**，锁住媒介、成像签名、色彩、光线、摄影语言、质感。
- 「产品锁块」在每条提示词**原样复用**，锁住结构、颜色分区、材质。
- 只有「场景与叙事块」在系列内变化：环境、道具、前中后景、情绪、机位、时间感。
- 每个场景沿用母版的同一套色彩系统与光线系统；不同场景之间只调「用量」和「落点」，不换系统。

## 场景差异化

在母版一致的前提下做变化，靠这些维度：

- 构图与机位（特写 / 中景 / 全景、俯 / 平 / 仰、焦段感、负空间分配）。
- 环境与道具（材质、体量、多少），但道具材质与场景质感要服从母版。
- 情绪节拍（叙事从「开箱/静置」到「使用/沉浸」）。
- 光线与时间感（晨光 / 午后 / 傍晚 / 夜间）。
- 前中后景层次与产品在画面中的占比。

不靠「换风格」来制造差异。

## 数量与画幅

- 默认画幅 16:9；用户可覆盖。
- 未指定场景数量时给 3 个差异化场景；用户要求 N 个就出 N 个（方向库最多 6 个）。
