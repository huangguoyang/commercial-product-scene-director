# 商业产品场景导演（commercial-product-scene-director）

把「参考图的风格」×「产品图的主体」合成商业大片级场景提示词。默认导向**真实拍摄**（影棚/样板间实拍）、氛围感好、配色高级；只输出可复制的提示词，不自动生图。

## 它能做什么

- 从**多张参考图**提炼统一的「风格母版」（光线、质感、色彩、构图、摄影语言、审美），取交集而非并集。
- 从**产品图**锁定「产品身份」（结构/颜色分区/材质），严格保持不变，并保证产品在场景里**自然落地**（尺度/接触/透视/光影）。
- 沿**叙事 × 审美**两个轴 + 默认方向库（日间 hero / 生活角 / 开放场景 / 建筑感广角 / 材质近景 / 夜间氛围）衍生多个差异化场景，产出系列一致、审美一致的场景提示词。
- **默认真实实拍**：影棚棚拍或样板间/展厅实景，反渲染、反塑料感，配色高级克制。
- 默认画幅 16:9，支持 MJ / FLUX / SD / 即梦等文生图工具。

## 触发方式（给 Claude 用的）

> 把这个产品做出参考图那种大片感
> 给我的产品做几张同风格场景图
> 参考这些风格图，给我的产品做商业 KV
> 做出影棚 / 样板间实拍的感觉

## 输出示例

```text
# 风格母版（跨参考图共性）
风格前缀块：...

# 产品身份锁（不可改变）
产品锁块：...

# 场景方案（系列一致，仅场景变化）
## 场景 1：{方向 + 叙事一句话}
完整提示词：...

# 使用建议
画幅默认 16:9；可选：把产品图作为参考图/垫图以更稳保形。
```

## 目录结构

```
commercial-product-scene-director/
├── SKILL.md                       # 触发词 + 工作流 + 纪律
└── references/
    ├── style-canon.md             # 风格母版（多图交集 + 成像签名四层分离）
    ├── photographic-realism.md    # 真实实拍 / 影棚样板间 / 高级配色审美
    ├── product-identity-lock.md   # 产品身份锁 + 自然落地 + 保真防线
    ├── scene-design.md            # 场景衍生 + 方向库 + 系列一致性
    └── output-contract.md         # 输出合同 + 覆盖审计
```

## 安装（Cherry Studio）

1. 下载本仓库。
2. 将整个文件夹放入 Cherry Studio 技能目录：`Data\Skills\commercial-product-scene-director\`。
3. 在 Cherry Studio 技能面板启用本技能（或重启后生效）。
